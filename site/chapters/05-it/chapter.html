Model the system before touching it.

  • CompMedic, LLC IT Technical Support 2008–2015
  • Miami Dade College A.A. to B.S. Biological Sciences (Biotechnology), Highest Honors 2009–2015

Fixing computers paid for my first degrees and taught me the method I still use on a process: model the system before touching it, then test the cheapest hypothesis first, from the wire up. A typical Monday call: the internet is down. The link light is on, the router answers, the outside world answers by address. Only the name lookup fails. I told the office manager: one computer is still asking for a server that was retired on Friday.

Methods · link, ARP, ping, name lookup

Order: bottom up, one test per layer, each run only after the one below passes. OSI layers 1, 2, 3 and 7 (ISO/IEC 7498-1). The DNS query rides on UDP port 53, layer 4; TCP/IP has no separate layers 5 and 6, so they get no test of their own. L1: link light on; adapter status Speed {{fact:it.key.speed}} (1000BASE-T). Green for link is a vendor convention, not an IEEE 802.3 requirement. L2: ping {{fact:it.key.gw}}, 4 of 4, time<1ms; arp -a lists {{fact:it.key.gw}} at {{fact:it.key.gwMac}}, dynamic (ARP, RFC 826). The request is a broadcast the switch floods to every other port; the reply comes back unicast. L3: ping {{fact:it.key.target}}, Windows defaults (4 × 32 bytes, ICMP echo, RFC 792): 4 of 4, 0 % loss, {{fact:it.key.echoes.0}}, {{fact:it.key.echoes.1}}, {{fact:it.key.echoes.2}}, {{fact:it.key.echoes.3}} ms; ({{fact:it.key.echoes.0}} + {{fact:it.key.echoes.1}} + {{fact:it.key.echoes.2}} + {{fact:it.key.echoes.3}}) ÷ 4 = 72 ÷ 4 = {{fact:it.key}} ms. L7: nslookup {{fact:it.key.name}}: “DNS request timed out. timeout was {{fact:it.key.nsTimeout}} seconds.” Server {{fact:it.key.cause}} (RFC 1034/1035). Cause and fix: PC-3 was set by hand years ago, when the old server ran DNS at .10. That server was retired on Friday, and every other desk gets DNS {{fact:it.key.fixDns}} from the router. Point PC-3 at {{fact:it.key.fixDns}} and {{fact:it.key.name}} resolves to {{fact:it.key.target}}, the address that already answered; the same four tests then pass. Identities: router LAN {{fact:it.key.gw}} / {{fact:it.key.gwMac}}, WAN 203.0.113.2; ISP gateway 203.0.113.1, resolver {{fact:it.key.resolver}}; PC-3 {{fact:it.key.pc}}. Addresses: composite case, no client data; RFC 1918, RFC 5737, RFC 9542 (formerly 7042), RFC 2606.
